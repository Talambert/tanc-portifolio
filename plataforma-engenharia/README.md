# 🧩 Plataforma de engenharia

A esteira para criar pipelines de dados: a biblioteca guarda o que se repete entre pipelines e o template gera um repositório novo a partir dela.

- [`lib-dataeng-core`](lib-dataeng-core/): biblioteca Python versionada (`dataeng-core`) e CLI `dataeng`. 🔨 Implementada e testada local; GCP não validado.
- [`template-pipeline`](template-pipeline/): gerador Cookiecutter de pipelines (`ingestao`, `relatorio`, `hibrido`). 🔨 Implementado e testado local; GCP não validado.

O que ainda não foi validado de verdade está descrito na seção "Plataforma de templates" do [README raiz](../README.md).
